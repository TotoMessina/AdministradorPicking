# Instrucciones del repositorio

Antes de trabajar, leer [.agents/rules/directrices_trabajo.md](.agents/rules/directrices_trabajo.md) (reglas de siempre). Según lo que toque la tarea, leer además solo la regla del tema que indica ese archivo: base de datos, producto o UI.

Para ubicar código, usar el Mapa de código de [README.md](README.md#mapa-de-código). No ejecutar migraciones remotas, builds ni pruebas automatizadas adicionales por iniciativa propia.
